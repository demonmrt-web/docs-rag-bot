# Автосубтитры

Скрипт делает файл `.srt` из видео или звука: локально, без облака и без платных сервисов. Распознавание речи — Whisper (`large-v3-turbo` через faster-whisper), на видеокарте NVIDIA или на процессоре.

Сделан для монтажа: готовый `.srt` открывается в Premiere Pro (File → Import) и других редакторах.

**Сделано вместе с Claude Code.** Я ставил задачи под реальные ролики и проверял результат на своих видео, а код писали и дорабатывали вдвоём с ИИ-ассистентом.

## Что умеет

- **Любой звук и видео** на входе (mp4, mov, wav, mp3 …): звук достаётся через ffmpeg.
- **Язык** — флагом `--lang`, суффиксом в имени файла (`ролик_fi.mp4`) или автоопределением по звуку. В списке с именами: финский, норвежский, итальянский, французский, немецкий, английский.
- **Режим «со сценарием».** Если рядом лежит текст (`.txt`, `.docx` или старый `.srt`), в титрах будет ровно он: Whisper нужен только для времени слов. Слова сценария выравниваются по распознанным, а пропущенные между соседями. Пустая строка в тексте задаёт границу титра. Если совпало мало слов (меньше 60%), скрипт предупредит, что текст или язык не те.
- **Нарезка титров** по паузам, длине строки и длительности. Есть склейка коротких «огрызков», разрез по знакам препинания, зазор в 2 кадра между титрами и возможность закрыть короткие паузы.
- **Пачка файлов** за один запуск: тексты называют так же, как ролики (`ролик1.mp4` + `ролик1.txt`).

## Установка

Нужен Python 3.10+ (Windows).

```
pip install -r requirements.txt
```

Для видеокарты NVIDIA раскомментируйте в `requirements.txt` строки `nvidia-cublas-cu12` и `nvidia-cudnn-cu12`. Без них используйте флаг `--cpu`.

Модель `large-v3-turbo` скачается сама при первом запуске. Если она уже лежит на диске, укажите папку:

```
set SUBTITLES_MODEL=D:\models\large-v3-turbo
```

## Использование

Перетащить ролик (и текст, если есть) на `СУБТИТРЫ.bat`, либо из консоли:

```
python subtitles.py ролик.mp4
python subtitles.py ролик.mp4 ролик.txt
python subtitles.py ролик.mp4 --lang fi --chars 42 --lines 2
python subtitles.py ролик.mp4 --cpu
```

Результат: `ролик.srt` (UTF-8) рядом с исходным файлом.

## Настройки

Файл `настройки.txt` рядом со скриптом (меняется число после `=`):

| Параметр | Смысл | По умолчанию |
|---|---|---|
| `слов` | максимум слов в титре (0 — без ограничения) | 2 |
| `длительность` | максимальная длительность титра, с | 3 |
| `минимум` | минимальная длительность, с | 0.5 |
| `символов`, `строк` | размер титра | 42 × 2 |
| `пауза` | пауза в речи, после которой титр начинается заново, с | 0.7 |
| `без_промежутков` | держать титр до следующего, если пауза не длиннее N сек | 2 |

Значения по умолчанию подобраны для коротких динамичных титров (Reels и Shorts). Для обычных субтитров поставьте `слов = 0`, `длительность = 6`.

## Честно о границах

- Проверено на Windows с видеокартой NVIDIA. На процессоре работает (`--cpu`), но заметно медленнее.
- Качество зависит от Whisper: на шуме, музыке и неразборчивой речи будут ошибки. Для этого и сделан режим со сценарием.
- Перевода нет: титры на языке речи.
