# Claude Browser Bridge

Расширение для Edge/Chrome и локальный сервер на Python, через которые ИИ-ассистент (Claude Code) работает с сайтами **в моём браузере**: читает страницы, нажимает кнопки, заполняет формы, прокручивает чаты — там, где у сервиса нет API.

Сделано в связке с Claude Code: я ставил задачи, проверял решения на реальных сайтах, находил и разбирал ошибки.

## Зачем

Рутина в веб-интерфейсах без API: просмотр рабочих чатов, заполнение анкет, однотипные действия. Скрипт даёт команды → расширение выполняет их в настоящей вкладке с моими входами в аккаунты.

Боевое применение:
- разбор 20 рабочих чатов в мессенджере MAX с поиском объявлений за две недели и сводкой в таблицу;
- заполнение и обновление резюме, поиск и разбор вакансий на hh.ru.

## Как устроено

```
скрипт / CLI  ──HTTP + ключ──▶  bridge.py (127.0.0.1)  ◀──long-poll──  расширение (service worker)
                                                                           │
                                                                           ▼
                                                          вкладка на разрешённом сайте
```

- `bridge.py` — очередь команд и результатов, CLI (`open`, `text`, `snap`, `click`, `type`, `key`, `scroll`, `wait`, `shot`, `fetch` …).
- `extension/` — MV3-расширение: выполняет команды в странице, снимок интерактивных элементов с номерами, ввод текста в React-формы и contenteditable-поля мессенджеров.

## Безопасность

- Сервер слушает только `127.0.0.1`; каждый запрос — с ключом; запросы с веб-страниц (чужой `Origin`) отклоняются.
- Работает только на сайтах из белого списка и только пока в расширении включён переключатель; добавить сайт может только человек.
- Капчи не обходятся: при капче работа останавливается и управление передаётся человеку.
- Ключ генерируется локально (`python bridge.py setup`) и не хранится в репозитории.

## Ошибки, найденные при разработке (и как исправлены)

- На Windows `SO_REUSEADDR` позволял запустить второй сервер на том же порту → команды уходили в «чужой» процесс. Запрещён повторный запуск.
- Ошибка «элемент не найден» возвращалась внутри успешного ответа → шаг считался выполненным. Теперь каждый шаг проверяет вложенный результат и фактическое состояние страницы.
- Синтетические клики не переключали чекбоксы React → добавлен нативный клик и чтение реального состояния.
- Зависание фонового процесса расширения на сетевом запросе → таймауты и автоперезапуск опросов.

## Запуск

```
python bridge.py setup      # создать ключ и extension/config.js
python bridge.py serve      # запустить мост
```
Edge → `edge://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка `extension`. В окне расширения: «Разрешить Claude работать», «Разрешить этот сайт».

Стек: JavaScript (Chrome Extensions, Manifest V3), Python (stdlib: http.server, urllib).
