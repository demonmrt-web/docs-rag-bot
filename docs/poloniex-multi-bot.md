# Мультивалютный бот Poloniex

Торговый бот для криптобиржи Poloniex с режимом симуляции и локальным веб-интерфейсом.
Сделан в связке с Claude Code: я формулировал правила стратегии и требования к рискам, проверял поведение бота в симуляции и на реальных данных.

Торгует всеми монетами на балансе. Прибыль фиксирует в той котируемой валюте (USDT, BTC, ETH, USDC…), где выручка в долларах максимальна с учётом стакана и комиссии.

## Логика (простыми словами)

1. Бот запоминает цену каждой монеты на старте (цена входа).
2. Монета подорожала на **3%** — бот следит за её максимумом.
3. Цена откатилась от максимума на **1%** — продаёт с прибылью (трейлинг).
4. Монета подешевела на **3%** от цены продажи — выкупает обратно, монет становится больше.
5. Упала на **12%** от входа — стоп-лосс.

Все параметры — в `config.yaml`. Есть дневной лимит убытка, ограничение проскальзывания по стакану, белый/чёрный списки монет.

## Веб-интерфейс

`python -m polobot web` (или `Запуск.bat`) → http://127.0.0.1:8080
- запуск и остановка бота;
- стоимость портфеля и график «с ботом / просто держать»;
- монеты и что бот по каждой ждёт;
- история сделок и журнал;
- изменение настроек с автоперезапуском.

## CLI

```
pip install -r requirements.txt
python -m polobot run       # запуск (по умолчанию симуляция)
python -m polobot report    # прибыль и сравнение с «просто держать»
python -m polobot reset     # начать симуляцию заново
```

## Безопасность

- По умолчанию `mode: paper` — симуляция, реальных сделок нет.
- Ключи API только в `.env` (в репозитории — `.env.example`); права ключа — **Read + Trade, без Withdraw**.
- Интерфейс доступен только с локального компьютера.

## Риски

Прибыль не гарантирована: при росте без откатов бот продаст рано; стоп-лосс фиксирует реальный убыток. Перед реальной торговлей — минимум 2–4 недели симуляции.

Стек: Python, REST API биржи, SQLite (журнал сделок), HTML/JS (интерфейс).
